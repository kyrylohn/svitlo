# Світло · група 5.1

Невелика сторінка для мешканців будинку: чи є світло зараз, графік відключень (ДТЕК Дніпровські електромережі, група 5.1) і статистика відключень за 7 / 30 днів.

- Сторінка: https://kyrylohn.github.io/svitlo/ (коротко — svitlo.deusops.net)
- Один файл `index.html`, без залежностей; шрифт Onest (OFL) лежить у `fonts/`.
- Дані — `data.json` у гілці `data` (один комміт, оновлюється з дому, коли щось змінилося, і щонайменше раз на 15 хв).
  Сторінка читає його з raw.githubusercontent.com, кешує в браузері й показує «дані на HH:MM»; якщо будинок без інтернету — попереджає, що дані застарілі.
- Час і межі доби — за Києвом.

Локальна перевірка: `python3 -m http.server` і відкрити `/?data=test-data.json`.
